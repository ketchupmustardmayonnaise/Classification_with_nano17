데이터셋 만들기

(1) dataset > print_mean_and_max
해당 코드의 path를 기준으로, 이미지 데이터 각 채널의 mean, max, std를 구함

(2) dataset > dataset_preprocess
데이터셋 전처리 후 파일로 저장함
* 만약 mean, max, std에 변동이 있을 경우 해당 코드에서 변수 바꿔 주면 됨
* 이미지에 대해 z-score로 처리하는 코드도 작성하였음. 해당 코드는 dataset > util.py 에서 확인 가능하며, preprocess_except_resizing 코드에서 수정하면 됨
* train dataset을 만들고 싶을 때는 dataset_type='train'
  validation dataset을 만들고 싶다면 dataset_type='val'
  test dataset을 만들고 싶다면 dataset_type='test'
  동일 경로에 있는 train, val, test 폴더에 대하여 데이터셋을 만듦

(3) dataset > outlier_filter
force에 대하여, 이상치는 Clipping함
현재는 z force가 0 이상이면 0으로, -5 미만이면 -5로 Clipping하고 있음
* path를 바꿔 가며 모든 데이터셋에 대하여 이상치 Clipping
path = 'train_dataset.h5'
path = 'val_dataset.h5'
path = 'test_dataset.h5'
